# 黎曼幸运数

把黎曼 ζ 函数的非平凡零点翻译成 大乐透 / 双色球 号码的小脚本。

**它不能预测开奖。** 开奖是独立随机事件，与本脚本没有任何因果关系；中奖概率与随手乱写完全相同（大乐透头奖 1/21,425,712，双色球头奖 1/17,721,088）。这里买的只是仪式感。

## 取号规则

黎曼猜想称 ζ(s) 的全部非平凡零点都在临界线 Re(s)=1/2 上。第 n 个非平凡零点写作

```
rho_n = 1/2 + i * gamma_n        gamma_1 = 14.134725, gamma_2 = 21.022040, ...
```

| 位置 | 公式 | 说明 |
|---|---|---|
| 大乐透前区 (1–35) / 双色球红球 (1–33) | `int(gamma) % 上限 + 1` | 取零点的**整数部** |
| 大乐透后区 (1–12) / 双色球蓝球 (1–16) | `int(frac(gamma) * 上限) + 1` | 取零点的**小数部** |

- 每期先用种子（默认当天日期 `YYYYMMDD` + 组号，或 `--period 期号`）打乱零点取样顺序，再用“取模 + 顺延去重”保证号码不重复。
- 同一个种子永远得到同一注号码，可复现、可复核。

## 安装

```powershell
python -m pip install mpmath
```

`mpmath` 用来实时计算 ζ 零点（`mpmath.zetazero(n)`），所以脚本永远跟着“最新零点表”走，不依赖硬编码数字。

## 用法

```powershell
python riemann_lucky.py                          # 今天日期作种子
python riemann_lucky.py --period 2026150         # 指定期号作种子
python riemann_lucky.py --sets 3 --zeros 200     # 出 3 组，取前 200 个零点
python riemann_lucky.py --game dlt               # 只出大乐透（ssq=只出双色球）
python riemann_lucky.py --trace                  # 显示每个号码来自哪个零点
python riemann_lucky.py --save                   # 追加写入 号码记录.txt
```

## 为什么取 200 个零点更好

前 60 个零点的整数部多在 14–200 之间，取模后号码分布还算均匀；但如果只取前 10 个零点，前区几乎只能落到十几个固定数字上。`--zeros` 越大，号码分布越散，仪式感也越足——数学意义仍然是零。
